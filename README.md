## كيف تعدّل الروابط

كل الروابط موجودة في ملف index.html، وفوق كل واحد منها تعليق يبدأ بكلمة «عدّل» وعددها خمسة مواضع فقط. الشعار مضمّن داخل الملف بصيغة base64 فلا يحتاج أي استضافة خارجية، وفيه بديل نصي يظهر تلقائيًا لو فشل التحميل.

## ملاحظات تقنية

الصفحة عربية بالكامل باتجاه RTL وتستخدم خط Tajawal من Google Fonts. زر المشاركة يعتمد على navigator.share مع بديل نسخ الرابط إلى الحافظة. الصفحة تدعم prefers-reduced-motion وحدود تركيز واضحة للتنقل بلوحة المفاتيح. النشر يتم عبر GitHub Pages من الفرع main.
